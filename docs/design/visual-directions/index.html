All images use the same deterministic scene and terminal font. The classic view shows more ground; the two closer concepts give each block and figure more screen space. These are early comparisons, not finished art.

Movement work is independent of this choice: held-key handling, input wake-ups, visible jumps and co-op physics prediction are being corrected. A visual choice should not trade away responsive controls.
