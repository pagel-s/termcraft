# Termcraft world atlas, 15 October 2026

[Open the gallery](index.html). It contains **78 scenes and 170 views**, including
three animations, captured with the renderer after
`3181b0930db2d66ec6040dfc45565ad56372147e` on `beta/terminal-reborn`.

This checkpoint adds capture tooling and a review gallery. It changes no gameplay,
physics, generation, entity art or installed executable. All game data is opened
in disposable temporary worlds; no player saves or model services are used.

## Coverage

- All ten native Overworld biomes: Plains, Forest, Desert, Tundra, Taiga, Swamp,
  Jungle, Extreme Hills, Ocean and River.
- Dawn, sunset, moonlight, thunderstorm, tundra snow and supported rain/snow shelters.
- Generated ore caves, deep caves, vertical cave/ravine geometry, both dungeon
  spawner types and a staged mining pose.
- Generated wooden/desert settlements, cottage, workshop, farmhouse, crop garden,
  square, night views and complete settlement panoramas.
- The generated stronghold complex, main portal chamber, library, silverfish area,
  eastern staging room and upper halls/ladder. Activated portal blocks are a
  separate, explicitly staged progression study.
- Nether cavern/roof context, soul sand, lava vents, underground lava-layer cutaway,
  complete fortress panorama, gatehouse, watchtower, blaze bastion, loot chapel,
  corridors/supports and a generated route shrine.
- Bridge and reliquary structure studies, with the generation limitation below.
- Generated End island, all four towers, walking cutaways, crystal anchors, return
  portal, island edge/void and an outer island scaffold. Side-view dragon and the
  opt-in front-facing art candidate are separate encounter cards over real terrain.
- Representative creatures/props and variants, trial camp/combat/jump/ravine,
  co-op composition, inventory, unsent game-master chat, a built portal/workshop,
  staged cave materials and the built-in Frostbound ruins world recipe.

The [catalog](catalog.json) gives each scene's origin, fixture source, image views
and native player/camera coordinates where applicable. Overview and Detail are
actual renderer zoom settings; they have different visible context. Panoramas and
tall views use larger terminal dimensions. The front-dragon detailed view uses a
taller viewport so the complete candidate fits. These are software rasterizations
of ANSI with square half-cell pixels, not terminal-emulator screenshots.

## Scene origin labels

Generated terrain is kept intact. Player/camera positions, time, and crystal entity
anchors are staged for inspection. `Generated + light` adds a supported inspection
torch to otherwise native cave/dungeon geometry. Water-biome cards may stage a
boat. Creature lineups, co-op avatars, weather fixtures, UI, mining pose and portal
activation are explicitly labelled. Chat is an **unsent draft**; it contains no
fabricated model response. Trial poses use scripted commands/game updates and
staged positions, rather than a human playthrough. The recipe tower comes from the
existing declarative example, with seed 42; it is not freshly generated by an LLM.

Native captures use seed data `[1337,7331,9917,4444]`; creature lineups use
`[42,73,99,44]`. The existing trial, weather and staged cave fixture examples define
their own scene setup. Their exact source files and capture inputs are hashed.

## Confirmed Nether generation finding

The route marker seed uses the multiplier `1_103_515_245`, offset `12_345` and
modulus `u32::MAX` (`4_294_967_295`). **All three are divisible by 3.** The marker
therefore always has remainder zero modulo 3, and the variant selector always
chooses Shrine, for positive and negative cells alike.

Sources: [marker construction](https://github.com/pagel-s/termcraft/blob/3181b0930db2d66ec6040dfc45565ad56372147e/src/world/mod.rs#L5803)
and [variant selection](https://github.com/pagel-s/termcraft/blob/3181b0930db2d66ec6040dfc45565ad56372147e/src/world/mod.rs#L5453).
The gallery records this issue without changing generation. Bridge/reliquary
cards are **source-derived staged block studies**, with simplified decoration,
based on the private builder footprints. They are not exact private-builder
replays or naturally generated discoveries.

The End outer islands and return portal retain their current scaffold behavior.
The front dragon remains a renderer art preview; its frontal combat geometry has
not been qualified. The lava-layer cutaway puts the camera/player inside the
underground lava layer and does not show a safe spawn or open lava coastline.

## Reproduction

Requires Rust, Python with Pillow, and the DejaVu Sans Mono font used by the raster
helper. Use a fresh output directory and unset `NO_COLOR` for each capture.

```sh
cargo build --release --locked --example world_review --example village_review --example entity_review --example weather_review --example lantern_review --example pixel_review --example nether_review
export atlas_raw=/tmp/termcraft-world-atlas
mkdir -p "$atlas_raw"
env -u NO_COLOR target/release/examples/world_review "$atlas_raw/worlds"
env -u NO_COLOR target/release/examples/village_review "$atlas_raw/villages"
env -u NO_COLOR target/release/examples/entity_review "$atlas_raw/entities"
env -u NO_COLOR target/release/examples/weather_review "$atlas_raw/weather"
env -u NO_COLOR target/release/examples/lantern_review "$atlas_raw/trial"
env -u NO_COLOR target/release/examples/pixel_review "$atlas_raw/pixel"
env -u NO_COLOR target/release/examples/nether_review "$atlas_raw/nether" --creatures --animate
python3 scripts/build_world_gallery.py "$atlas_raw" /tmp/termcraft-world-gallery
python3 -m http.server 8774 --bind 127.0.0.1 --directory /tmp/termcraft-world-gallery
```

The gallery embeds its catalog and uses no external JavaScript/fonts or backend;
the HTML can also be opened locally. The builder emits contact sheets next to the
raw capture directory for visual review. Incremental animation frames are decoded
in order. The Nether clip has 72 samples at 60 Hz with a 20/10/20 ms GIF timing
pattern. Rain/snow clips have 48 samples at 20 Hz. These do not establish achieved
FPS, input latency, network behavior or human gameplay acceptance.

[Build/source/capture evidence](evidence.json) and [raw ANSI input hashes](capture-inputs.json)
identify the reviewed artifacts. This gallery alone does not qualify a beta release.
