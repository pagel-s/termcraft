Survival creates a naturally generated world; Lantern Run is a hand-built challenge. Each mode keeps its own browser save. Clearing site data removes these saves; export backups to keep them. Native saves are separate. Browser multiplayer is not available yet.

In the inventory: click to move or merge, right click to split, Shift+click to transfer. Enter crafts from the grid; Shift+Enter crafts the maximum. F uses the hovered block. Escape closes menus or pauses.
