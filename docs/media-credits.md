# Media credits

The screenshot in the README and documentation is captured directly from
Termcraft's terminal renderer. It shows a generated village with a staged camera
position and is not a recording of manual play.

The beta gameplay showcase (`docs/assets/termcraft.mp4`) and its short README
preview (`docs/assets/termcraft.gif`) use actual co-op recordings by Sebastian
Pagel, captured on 25 October 2026 in the Detail view. The trailer includes
original flat pixel-block lettering and editorial sound design. The thumbnail is
a frame from the dragon encounter with the trailer wordmark.

The beta showcase and the [original alpha highlight video](https://youtu.be/kR986Xqzj7E)
use these music tracks:

- [Fantasy Orchestral Theme](https://opengameart.org/content/fantasy-orchestral-theme) by Joth — CC0.
- [Boss Battle #2 (Symphonic Metal)](https://opengameart.org/content/boss-battle-2-symphonic-metal) by nene — CC0.

The beta video is 70 seconds at 1920×1080 and 60 fps, with stereo audio. There
are no added gameplay captions. The final seconds show only TERMCRAFT and the
GitHub URL over the continuing gameplay footage. Its
proposed YouTube description, chapters and credits are saved alongside it in
`docs/assets/termcraft-video-description.txt`.

Large video and preview assets are kept out of native game archives and Cargo
packages. The original OBS recordings are not included in the repository.
